Порядок работы

Как работать с Jules с телефона: от идеи до живого сайта

Ничего устанавливать не нужно: Jules открывается в браузере телефона, а GitHub и хостинги работают через свои мобильные страницы.

  1. Телефон

    Опиши задачу

    Открой jules.google, выбери репозиторий и ветку, напиши задачу обычным языком.

  2. Jules

    Агент работает

    Клонирует репозиторий в облачную машину, пишет код, показывает план и результат.

  3. GitHub

    Pull request

    Jules публикует изменения в ветке. Прочитай diff и слей PR прямо с телефона.

  4. Vercel / Render

    Автодеплой

    Хостинг следит за веткой main и сам выкатывает новую версию после слияния.

  5. Val Town

    Пинг /health

    Расписание обращается к адресу здоровья бэкенда, чтобы Render не успел уснуть.

Куда выкатывать

Бесплатный хостинг: Vercel, Render и Val Town в одном проекте

Фронтенд

Vercel

Сайты на React, Next.js и статика. Подключаешь репозиторий, дальше каждый коммит в main превращается в новую версию сайта. Тариф Hobby бесплатный для личных проектов.

Бэкенд

Render

API, боты, Python-серверы. Бесплатный сервис засыпает, если к нему долго никто не обращается, и первый запрос после сна идёт медленно. Лимиты часов проверь в тарифе.

Расписание и мелкие API

Val Town

Маленькая функция с таймером запускается по расписанию и обращается к /health на Render. Подходит и для простых эндпоинтов и webhook без отдельного сервера.

Перед стартом

Что проверить перед использованием

  • Лимиты меняются. В мае 2025 бесплатных задач было 5 в день, в августе уже 15. Сверяйся со страницей лимитов Jules.
  • Читай каждый PR. Агент может ошибиться. Сливай изменения только после просмотра diff и зелёных проверок.
  • Секреты не в код. Ключи и пароли храни в переменных окружения Vercel и Render, а не в репозитории.
  • Бесплатные тарифы хостингов. Условия Vercel, Render и Val Town проверь на их страницах цен, они обновляются независимо от Jules.

Вопросы и ответы

Частые вопросы про Jules

Jules бесплатный?

Да, у Jules есть бесплатный тариф: 15 задач в день и 3 задачи одновременно. Нужен личный аккаунт Google и возраст от 18 лет. Google оставляет за собой право менять лимиты, поэтому актуальные цифры смотри на jules.google.

Правда ли, что Jules бесплатный до 11 ноября?

Подтверждения этой даты в официальных источниках на 30 октября 2026 найти не удалось. Бесплатный тариф Jules существует постоянно, а лимиты Google время от времени меняет. Срок и условия проверяй на jules.google.

Что такое Jules?

Jules это асинхронный агент для программирования от Google Labs. Он клонирует репозиторий GitHub в облачную виртуальную машину, пишет код по описанию задачи и публикует изменения в виде pull request. Общий доступ открыт с августа 2025 года.

Можно ли работать с Jules с телефона?

Jules работает как веб-приложение на jules.google, поэтому отдельная установка не нужна и задачу можно поставить из браузера смартфона. Проверить и слить pull request можно через GitHub Mobile или мобильную версию сайта GitHub.

Сколько стоит Jules в Google AI Pro?

Jules входит в подписку Google AI Pro, которая по данным обзоров стоит 19,99 долларов в месяц и даёт 100 задач в день и 15 одновременных задач. Точные условия указаны на страницах Google.

Как бесплатно выкатить сайт, который написал Jules?

Подключи репозиторий GitHub к Vercel для фронтенда или к Render для бэкенда. После слияния pull request в ветку main хостинг выкатывает новую версию автоматически. Для расписаний и мелких API подходит Val Town. Лимиты бесплатных тарифов проверяй на страницах цен сервисов.

Почему бесплатный сервис на Render засыпает и что с этим делать?

Бесплатный веб-сервис на Render останавливается после периода без запросов, и первый запрос после паузы выполняется медленно. Обходной путь: функция Val Town по расписанию обращается к адресу /health. Проверь, как такие запросы влияют на лимит бесплатных часов в твоём тарифе Render.
